# HAT LOVE ♡

Site romântico em HTML, CSS e JavaScript, sem dependências de build.

## Abrir
Abra `index.html` no navegador ou use a extensão Live Server no VS Code.

## Publicar na Vercel
Importe esta pasta como projeto estático, sem comando de build, e publique.

## Arquivos
- `index.html`: estrutura e carta final
- `style.css`: aparência responsiva e animações
- `script.js`: capítulos, surpresas, progresso e música instrumental original
- `assets/`: ilustrações em WebP

A música só começa depois do clique no botão ♫, respeitando as regras dos navegadores. O áudio é sintetizado pelo navegador, não depende de internet. A fonte externa é opcional e tem fontes alternativas locais.

Algumas cenas ilustradas contêm falas fictícias ou detalhes decorativos. Os textos interativos do site preservam a cronologia relatada.
